# Play Page Extraction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move soccer, tournament, Floor is Lava, marble race and the companion
heads engine out of `index.html` onto a dedicated `play.html`, taking
`index.html` from 830,783 to ~364,783 bytes.

**Architecture:** Six new files loaded by plain `<script src>` / `<link>` — no
build step. The companion IIFE moves **whole** into `play-engine.js` because
soccer, lava and the race share its closure with the ambient head. `index.html`
loads the engine only when the visitor has saved heads and "Show on home" is on.

**Tech Stack:** Vanilla ES5 in static files. `python3 -m http.server 4173`.
`node --check` as the syntax gate. Real Chrome for verification.

**Spec:** `docs/superpowers/specs/2026-08-02-play-page-design.md` (commit
`8caad90`, amended with §5.6–5.7). Read it before Task 1.

## Global Constraints (inherited — every task)

- **Nothing is deleted from `index.html` until Task 5.** Tasks 1–4 only add
  files. The engine exists in two places during that window, deliberately, so
  the change stays cheap to steer.
- **Syntax gate after every edit:** `python3 tools/hm-check.py` → `syntax OK`.
- **`index.html` defines things twice** — grep ALL occurrences before removing
  any selector or function name.
- **Guard conditional globals cross-block** (`__hmBus`, `__hmSess`, `__hmSlow`,
  `__hmFxAt`, `__bcMat`); a no-heads visitor never boots the engine.
- **`@media` adds no specificity** — scope mobile overrides.
- **Never put `filter` on an ancestor of the split-flap cells.**
- **One change per pass;** revert anything that regresses.
- **Verify at `http://localhost:4173`.** The embedded preview pane white-screens
  on the SVG ink filters and throttles rAF — use real Chrome, or `?wraf=1`.
- **`?wraf=1`** drives rAF from a Web Worker so a backgrounded tab keeps
  ticking, and exposes `window.__peers` / `__plats` / `__race`. `?stand=1` does
  not exist.
- **Jayden's real Chrome holds his live `localStorage`.** Snapshot
  `hmCompanions` / `hmCompanion` before seeding test heads and restore after.
  His real bakes are ~900k chars; test heads are far smaller.
- Seeded test heads need complete geometry (`marks.BL/BR/M/N` plus `eyes` with
  `x,y,w,h,ang,sc,ic`) **and unique marks/eyes per head**, or `spawnCompanion`
  throws on `marks.BR` and aborts the whole IIFE — which looks like "the engine
  won't run" but is bad data.

The current `/tmp/hm-check.py` only checks `index.html`'s inline blocks, and

```python
import re, subprocess, tempfile, sys, os, glob
ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
fail = 0

def check(label, source):
    global fail
    with tempfile.NamedTemporaryFile('w', suffix='.js', delete=False) as f:
        f.write(source); p = f.name
    r = subprocess.run(['node', '--check', p], capture_output=True, text=True)
    os.unlink(p)
    if r.returncode:
        fail = 1; print(label, 'FAIL\n', r.stderr[:400])

for html in ['index.html', 'play.html']:
    path = os.path.join(ROOT, html)
    if not os.path.exists(path): continue
    for i, (attrs, body) in enumerate(
            re.findall(r'<script([^>]*)>(.*?)</script>', open(path).read(), re.S)):
        if 'ld+json' in attrs or 'src=' in attrs or not body.strip(): continue
        check('%s block %d' % (html, i), body)

for js in sorted(glob.glob(os.path.join(ROOT, '*.js'))):
    check(os.path.basename(js), open(js).read())

print('syntax OK' if not fail else 'SYNTAX FAILURES'); sys.exit(fail)
```

Note the two skips: `ld+json` (JSON-LD always fails `node --check` — a known
false positive) and `src=` (external refs have no inline body).
